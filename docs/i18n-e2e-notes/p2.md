# P2 (Regie shell and stage): strings the E2E tests may assert

Written for package P7. "Old German" is the former UI text, "New English" the text the Regie shows now (language `en`).
The German text is unchanged and lives in `packages/i18n/src/messages/de-CH/regie-{core,header,monitoring,stage,statusline,workspace}.ts`.
The "E2E files" column lists up to four files under `tests/e2e` that contain the first words of the old text (a hint, not a complete list).

Notes for P7:

- English numbers use a decimal point and "%" without a space ("0.3 s", "0.5%", "2.8"); German keeps the comma ("0,3 s", "0,5 %").
- The "Control room" wording is only used where the old text said "Regie" in a sentence; the document title is "StudioFlow Control room" (`regie.core.appTitle`).
- The `LogEntryDto` lines in "Letzte Ereignisse" are now rendered from `code` and `params` (`regie.log.*`), the API `text` is only the fallback.
- New or changed accessible names: the region of the message strip, the dock grip, the splitters and the overlay are `[attr.aria-label]` bindings now (same names, English).
- The Regie page no longer sets `lang="de-CH"` on `sf-studio-page`, `sf-toast-host` and `sf-monitoring-page`; they inherit `<html lang>`.
- Server defaults that the unit-test fixtures mimic are English (D8): scenes "Welcome", "Presentation", "Break".
