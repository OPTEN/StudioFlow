# P1 notes for the E2E conversion (P7): sender, device runtime, output page

User-visible text of `apps/sender`, `apps/output` and the shared device-side packages changed from German to English
(the German text is unchanged in `packages/i18n/src/messages/de-CH/`). `data-testid`, `data-state` and class names are
unchanged. Strings are `old German → new English`; the German form is shown by the `de-CH` setting.

## URLs

| Old | New |
|---|---|
| `/join/warten` | `/join/waiting` |
| `/o/_uhr` | `/o/_clock` |

The output page also accepts `&lang=de-CH` (ignored by the route parser; read by `main.ts`).

## Wire and report values

* The platform label the sender reports (`DeviceDto.platform`, hub `Hello.platform`) is `Unknown platform` / `Unbekannte Plattform`
  when nothing is recognised; it follows the language of the sender when the report is built.
* `TechCheckDto.note` is an English summary whatever the language of the sender, for example
  `Camera: only 640 × 360 at 30 fps. Network: high latency (200 ms). Upload: only 4 Mbit/s (recommended from 6 Mbit/s).`
  The `problems` of a check stay on the device and are not part of the report.
* The tech check `TimeoutError` message is now `Timed out after 15000 ms` (a diagnostic text, not shown).
