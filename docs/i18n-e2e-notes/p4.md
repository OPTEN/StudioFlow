# P4 (API): texts that E2E may assert

Package P4 of issue #6 turned every German text of `apps/api` into English. This page lists each user-visible string
that changed, `old German -> new English`, with the E2E places that assert the old text (found by grepping
`tests/e2e` on the branch point). Package P7 converts those assertions.

The Regie and the sender never show the server `detail` or field messages (D7); they show their own catalogue texts,
chosen by `code`. So the API texts matter for E2E only where a test calls the API directly (REST, hubs, `sync-client`)
or reads a server-created default that a UI shows (scene names, slates, device labels, log lines).

## ProblemDetails `detail` and field messages

Asserted today: `specs/auth/auth-lockout.disruptive.spec.ts:39` (`/\d+ Minuten/` -> `/\d+ minutes?/`; the English text
says `1 minute` for a wait of 60 s or less), `specs/media/media-rest.spec.ts:84` (only "has a reason", label says
"German reason"), `specs/auth/auth-session.spec.ts:63` (wrong password and unknown user have equal details; unchanged).
`specs/sync/sync-hub.spec.ts:28` expects a hub error that matches `/not_found/`; the code prefix is unchanged.
